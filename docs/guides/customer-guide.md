# Customer guide

Sign in at the panel address you were given. **Your servers** lists every server with its plan,
status, next due date and renewal price.

Open a server to:

- see whether it is running, its IP addresses and the SSH login (`ssh cloud@<ip>`);
- **Start**, **Shut down** (clean shutdown), **Reboot**, or **Force stop** (cuts power — use only
  if the server does not respond);
- view CPU use over the last hour.

Suspension, renewal and cancellation are handled by whoever bills you (your hosting provider's
billing portal). If a server shows *Suspended*, settle the outstanding invoice there.

If you bought through a reseller's website, use that website's client area — it shows the same
server through the CloudPilot module.
